# ✈️ Trip Planner

個人旅行計畫集合，用 HTML + Tailwind CSS 製作的互動式行程頁面。

## 🇳🇱🇧🇪🇫🇷 2026 歐洲之旅 — 荷蘭・比利時・法國

**日期：** 2026/06/13 - 06/20（8天7夜）

**路線：** 阿姆斯特丹 → 安特衛普 → 布魯塞爾 → 巴黎

### 功能

- 📅 每日行程總覽卡片（2 欄佈局）
- 🗓️ 可展開的詳細時間表（手風琴式）
- 🗺️ 每日 OpenStreetMap 嵌入地圖
- 💡 每天備選行程推薦
- ✅ 出發前準備清單（勾選進度自動儲存）
- ⏱️ 出發倒數計時器
- 🔄 中英文切換（localStorage 記憶）
- 📱 響應式設計（手機 / 平板 / 桌面）

### 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需要任何伺服器或安裝。

### 技術

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Google Fonts (Noto Sans TC / Noto Serif TC)
- OpenStreetMap Embed
